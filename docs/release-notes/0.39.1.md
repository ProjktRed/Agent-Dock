- **Web access for agents is off by default.** It is now your own opt-in in every safety level
  (Settings › Execution & safety › Web access for agents), and turning it on asks you to confirm. 0.39.0
  had it on by default, so updating turns it off once; turn it back on if you use it, and it stays as
  you set it from then on. Web pages can carry instructions aimed at agents, so it is better off unless
  a task needs it. Thanks to kadono for the suggestion.
- **Security: Cline gets only the key it needs.** Cline is started with just the variable for its
  configured provider (holding the key broker's token, as in 0.39.0), and no other provider key from
  your environment. Thanks to kadono.
