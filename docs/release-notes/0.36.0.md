- **Interface styles.** Settings › General › Appearance has a Style choice with previews: Neumorphic
  (the current look), Standard (flat dark panels, thin borders) and Cyberpunk (neon on near-black, angled
  edges). Dark and Darker apply to every style, and each style remembers its own accent color. Fonts are
  bundled with the app, so nothing is downloaded.
- **Consistent UI.** One style each for selected items, segmented controls, toggles and buttons across
  every page. Dates and numbers are always shown in English. Plurals are correct, empty sections say so,
  and a finished run shows a summary instead of empty task details.
- **Security hardening.** Tools are looked up only on PATH. Notification settings stay inside the engine.
  Imported settings never set program locations or turn off the tool guard. Claude Code reads only your
  own user settings. Agent config folders (`.claude/`, `.codex/`, `.opencode/`, `.husky/`,
  `.github/workflows/`, `.vscode/` and others) are protected by default. Arguments passed through
  cmd.exe are escaped. Developer tools and the default menu are off in installed builds. Details are in
  docs/security.md.
- **Parallel tasks, more reliable.**
  - A round that stops for you, or is blocked, now shows in Activity and sends its notification.
  - A usage-limit wait clears as soon as no task is waiting.
  - Only the main run sends notifications and Supervisor alerts, so nothing arrives twice.
  - A merge that a pre-commit hook refuses no longer leaves your branch dirty.
  - Files that change while the combined check runs are never restored or deleted. The round stops and
    lists them.
  - Task engines left running by a crash are stopped before the next round, and their usage is counted
    once.
  - Each merged task shows its attempt count, and the Tokens tab shows usage per role for parallel tasks.
- **Scheduled runs while closed.** Tasks now start on battery, run as soon as possible after a missed
  start, and can wake the PC (new Wake to run option). Missed or failed scheduled starts go to your
  notification channels. A 23:50 schedule checked just after midnight counts as on time.
- **Smaller updates work in the installed app.** The update assembly reads the app archive as a file.
- **User guide offline.** Settings › Help opens the bundled user guide and How it works.
- **Fix:** an Assessment answer missing its "Task skill:" line is sent back once with the reason,
  instead of blocking the run.
- **Fix:** settings and project files retry a locked rename for up to 5 seconds, like the engine.
