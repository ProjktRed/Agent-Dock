- **A new install starts clean.** Setup registers only the CLIs and local model servers it finds on
  your computer and points the agents at them. Nothing from anyone else's setup is preset: no local
  model, port or CLI list. **Detect again** (Setup) and **Find installed** (CLIs) add tools you
  install later, and any connection can now be removed.
- **llama.cpp without a launcher script.** With a models folder set, Agent Dock starts `llama-server`
  from PATH itself, on the connection's address. The engine now always uses the address set for
  llama.cpp and Ollama in CLIs (it used to assume a fixed port).
- **Local model tokens count toward token budgets** in Unattended mode.
- **Better plans from local models:** the planner now also reads the start of the project's most
  relevant source files.
- **Fewer false refusals on Windows:** the tool guard treats a short (8.3) or differently cased path
  to an allowed file as that file.
- **Fewer interrupted runs:** state saves retry for about five seconds when antivirus or indexing
  briefly locks a file.
- Updates and releases come from this repository; development runs keep their own settings folder.
