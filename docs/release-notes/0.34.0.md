- **Scheduled runs.** Start a project's automation at a set time on chosen days while Agent Dock is
  open (Projects › Workflow). Pair it with Unattended mode for overnight runs.
- **Pull-request mode.** Each new run works on its own `agent-dock/run-…` branch. Nothing is pushed
  until you press **Open pull request**, which pushes the branch and opens the pull request (GitHub CLI,
  or GitHub's compare page).
- **Parallel lanes.** Run another objective at the same time in a git worktree of the project, on its
  own branch with its own engine. Each lane shows up as its own project.
- **WSL isolation (opt-in).** A project's engine and agent CLIs can run inside a WSL distro.
  **Check distro** shows whether Node.js, git and your CLIs are installed there.
- **Run a task again** from Task history, with the same prompt, files and check. Tasks are kept from
  this version on.
- **Estimate before Start.** Overview estimates the time, tokens and spend for the rest of the plan,
  based on this project's recent pace.
- **Export a run report** as Markdown or HTML from Overview › Runs.
- **First smaller update.** Updating from 0.33.0 downloads only the files that changed.
