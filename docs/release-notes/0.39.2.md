- **Security: agents and checks no longer inherit unrelated credentials.** Cline, check commands and
  agent shells now drop every environment variable named like a credential (API keys, tokens,
  passwords, secrets), not only a fixed list of provider keys. Each agent CLI still gets its own
  sign-in variable. If a check relied on a token from your environment (for example `GITHUB_TOKEN`),
  it no longer receives it. A custom provider key variable is now also hidden in logs. Thanks to kadono.
