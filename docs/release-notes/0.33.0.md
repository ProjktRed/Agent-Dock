- **Spend budgets cover Codex.** Codex reports tokens but no cost, so its spend never counted. Add
  your models' prices in Settings › Execution & safety › Price table (USD per million tokens; `gpt-5*`
  matches every model starting with that). Run reports show how much of the spend is estimated.
- **Fixer workflow role.** A before-QA gate can now fix what it finds itself, once per attempt, before
  the attempt goes back for correction. The fix runs with the tool guard always on, may edit only the
  task's approved files and never commits; the engine checks the result again before QA.
- **Claude limits without the extra call.** Every Claude Code run already reports the plan's limits;
  the engine now saves them, and the Limits card uses them while they are recent. The previous method
  remains as the fallback when no run has reported recently.
- **Linux AppImage (preview).** Each release now includes `AgentDock-<version>-linux-x86_64.AppImage`,
  signed separately. It updates itself from signed releases like the Windows app.
- **Smaller updates, from the next release on.** Releases now publish a signed list of every file.
  From the release after this one, an app on the previous version downloads only the changed files
  (about a third less), rebuilds the new version and checks every file against the signed list. If
  anything does not match, it downloads the full release as before.
