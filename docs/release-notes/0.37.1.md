- **Fix:** Save plan works again when you create a plan with a model while adding a project. The phase
  and task count behind the button was always 0, so Save stayed disabled, with or without Regenerate.
- **Capped API keys.** Where you enter a cloud API key (CLIs), Agent Dock now recommends a key made only
  for it, with a low spending limit set at the provider, so a leaked key costs at most that limit. The
  run and daily budgets in Settings stay the limit inside the app. Suggested by kadono.
- **Warning for OpenRouter keys without a limit.** Before a run, Agent Dock asks OpenRouter whether the
  key has a credit limit (at most once an hour) and warns when it has none.
