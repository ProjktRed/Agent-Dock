- **Fix (Windows): Codex runs with Agent Dock's protection hook again.** On Windows, Codex could not
  start the hook that keeps it inside a task's files and away from protected paths. Codex implementation
  runs stopped with "Codex ran tools without the scope hook". The hook now starts correctly, a hook that
  fails to start blocks the tool call, and every Codex run (QA, Assessment, Resolver and Elevation too)
  stops if the hook never checked a tool call. Linux was not affected.
- **CLI settings for Cline and OpenCode** (CLIs › Settings). Cline: retries and context compaction.
  OpenCode: max steps per task and the reasoning variant. Both apply when they implement a task, and
  none of them loosens what Agent Dock allows.
