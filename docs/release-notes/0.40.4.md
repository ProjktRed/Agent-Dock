# Agent Dock 0.40.4

- **Fix: `printf`, `awk` and `find` with `%s` aren't refused outright any more.** 0.40.3 read any `%` and a letter
  as a cmd.exe loop variable when checking for hidden protected names. It now counts only where a cmd `for` loop
  declares one.
- **Fix: a Codex that can't list its features is refused.** Agent Dock runs Codex without terminals and checks
  that Codex agrees. A Codex whose feature list couldn't be read was let through unconfirmed; it is now refused
  with a message to update Codex.
- A test no longer depends on files in your home folder. Thanks to kadono.
