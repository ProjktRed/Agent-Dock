# Agent Dock 0.40.3

- **Fix: cmd.exe escapes can no longer disguise a protected file in an Ask.** With "Ask" on, a command that hid a
  protected name behind cmd.exe's escape character or a variable expansion (`.g^it`, `.e%X%nv`) was put to you
  instead of refused, and a yes read the file. Those forms are now refused outright, like `.e*` and `.e''nv`.
