- **Task size: Eco, Standard and Max** (Settings › Workflow rules, or per project in Projects ›
  Workflow). **Eco**, the default, keeps today's small tasks. **Standard** does one plan item per
  task, code and tests together, for Pro, Max or API plans and large local models. **Max** has no
  size limits; it asks before turning on.
- **Max limits.** While Max is on, a sidebar button above Collapse holds your own limits for files,
  new file size, files to read and the implementation timeout. All are empty (no limit) at first.
- **Suggested mode** from your plan and the Implementation model's context. It never switches by itself.
- **Step down.** In Standard or Max, a task that fails review twice is set aside (its work kept in a
  git stash) and redone one size smaller, then the run goes back to your size.
- **Estimates and reports per mode.** Overview compares the task sizes this project has run in. Run
  reports and exports show the task size, step-downs and plan items finished.
