- **Task size: Eco, Standard and Max** (Settings › Workflow rules, or per project in Projects ›
  Workflow). **Eco**, the default, keeps today's small tasks. **Standard** does one plan item per
  task, code and tests together, for Pro, Max or API plans and large local models. **Max** has no
  size limits; it asks before turning on.
- **Max limits.** While Max is on, a sidebar button above Collapse holds your own limits for files,
  new file size, files to read and the implementation timeout. All are empty (no limit) at first.
- **Suggested mode** from your plan and the Implementation model's context. It never switches by itself.
- **Step down.** In Standard or Max, a task that fails review twice is set aside (its work kept in a
  git stash) and redone one size smaller, then the run goes back to your size.
- **Estimates and reports per mode.** Overview compares the task sizes this project has run in. Run
  reports and exports show the task size, step-downs and plan items finished.
- **Much smaller updates.** The app's exe now arrives as a binary patch of a few kilobytes instead
  of 236 MB, checked against the signed file list; anything that does not match falls back to the full
  download. Applies to updates from this version on.
- **Scheduled runs while Agent Dock is closed** (Windows, opt-in per project): Task Scheduler launches
  the app minimized at the scheduled time. No admin rights needed. With two installs on one PC, each
  keeps only the tasks that launch its own exe and leaves the other's alone.
- **Uninstall removes the scheduled tasks** that launch this install; updating keeps them.
- **User guide** (docs/user-guide.md, also under Settings › General › Help): getting started, task sizes,
  unattended runs, spend, pull requests, lanes and troubleshooting.
- **Parallel tasks** (up to 4 at once, cloud Implementation agents): each task runs in its own git
  worktree with its own Implementation and QA; every approved change is checked again on the combined
  code before it is committed to your branch. Pause, Stop and Automatic continuation off apply between
  rounds as between tasks, run reports and daily spend include every task's tokens, and a change that
  fails to merge twice stops the run for you.
- **Clean up parallel worktrees** (Projects › Workflow): removes the worktrees and branches kept from
  parallel tasks that did not finish or merge, without touching the project's own `node_modules`.
