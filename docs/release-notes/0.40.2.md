# Agent Dock 0.40.2

- **Fix: Claude runs on Linux could do nothing while reporting success.** 0.40.1 turned on Claude Code's subprocess
  scrub, which on Linux also starts Claude Code's own sandbox, even when sandboxing is off. Without socat that
  sandbox can't start, so every command failed, yet the run reported success. Where Claude Code says its sandbox
  can't start, a run with an Anthropic key in its environment is now refused with what to do (install bubblewrap and
  socat, or sign Claude Code in with /login), and a run signed in without a key goes without the scrub. A run whose
  commands failed for that reason is refused.
- **Fix: Codex runs without terminals.** Codex could type into a command it had started in a terminal, past the
  guard, for example into a shell started by an approved `npm run` script. Codex now runs with terminals off, so a
  running command's input is closed. A Codex that still reports terminals on is refused (update Codex). The guard
  also refuses more forms that read code from input (`sh -c bash`, `cat | sh`, `npx bash`).
- **Fix: fewer false refusals.** Combined options (`bash -lc`, `sh -ec`, `node -pe`), `bun` and `deno` subcommands,
  and `sqlite3`, `psql` or `mysql` with a query on the command line run as usual. With "Ask" on, `ls *` and
  `echo $(date)` are put to you instead of refused; a wildcard that singles out a protected file (`.e*`) is still
  refused outright.
- **Fix: Codex's empty folders are cleaned up when TMPDIR points elsewhere.** The empty `.git`, `.codex` and
  `.agents` folders are removed from `/tmp` as well as from TMPDIR's folder.
- Smaller fixes: bash's `$'…'` strings are decoded before the protected-file check; the web-fetch check treats the
  IPv4-translated IPv6 form (`::ffff:0:a.b.c.d`) as the address inside; Cline no longer inherits SSH agent, password
  helper or npm user-config variables; the decision log knows five more Claude Code tools. Thanks to kadono.
